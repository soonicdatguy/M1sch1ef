A tiny, mischievous static chatroom. No accounts, no servers — just
HTML/CSS/JS. Chats sync between open tabs/windows of the same browser via
`firebase`

> Inspired by the "tabchats" idea: a chatroom that lives entirely in your
> browser tabs.

## Features

- Multiple rooms (lobby, pranks, hacks, random, secrets)
- **Direct messages** (click `+ DM` and enter an alias)
- Pick a nickname (stored locally)
- Real-time sync across tabs/windows on the same device
- Unread badges on inactive tabs
- Messages persist per-channel in `localStorage`
- 100% static — no backend, no build step
- Dark mischief aesthetic with neon accents
- SVG logo + favicon (standalone, viewable directly)
- SVG all in one
